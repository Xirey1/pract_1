# Эмулятор командной оболочки, вариант №11

Этап 1: REPL, приглашение `VFS:/$`, парсинг аргументов, подстановка переменных окружения, сообщения об ошибках, заглушки `ls`/`cd`, выход через `exit`.

Запуск: `python main.py`.

Этап 2: `--vfs`, `--script`, `--batch`, команда `conf-dump`. Скрипт выводит исходные команды на экран и останавливается при первой ошибке.

Пример: `python main.py --vfs demo.zip --script demos/stage2_ok.vfs --batch`.
